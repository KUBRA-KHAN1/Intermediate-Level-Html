# University Website

## About the Project
This is my second HTML project. I created a simple University Website using HTML5 only.

The purpose of this project is to practice HTML forms, tables, navigation and multiple web pages.

## Pages Included
1. Home Page
2. About University
3. Departments
4. Courses
5. Admission Form
6. Contact Page

## Technologies Used
- HTML5

**Note:** This project is created using HTML only. No CSS or JavaScript is used.

## HTML Topics Covered
- HTML Basic Structure
- Headings and Paragraphs
- Hyperlinks
- Images
- Ordered and Unordered Lists
- HTML Tables
- Table Rows and Columns
- Colspan and Rowspan
- HTML Forms
- Text Input
- Email Input
- Password Input
- Radio Buttons
- Checkboxes
- Dropdown Lists
- Textarea
- Labels
- Fieldset and Legend
- Semantic HTML
- Multiple Page Navigation

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## Project Purpose
This project helped me improve my HTML skills and understand how to create a multi-page university website.
